# Hidden Coin

Consider the following game played between Alice and Bob.
Alice has a coin that she hides in either a red or a blue box.
Bob picks a box. If Bob does not find the coin, he gets \$0.
If Bob finds the coin in the red box, he gets \$2.
But if Bob finds the coin in the blue box, he gets \$1.

Also, after a player plays, they tell the other player what strategy they used.
So if Alice starts with the strategy of always picking the blue box, Bob knows to just pick the blux box and get \$1.

This is interesting with randomized strategies, where if Alice tells Bob she will pick either box with probability $1/2$,
then Bob now picks the red box and wins \$1 on average.

If Bob tells Alice that he will pick a box randomly with probability $1/2$ for each box, then Alice will always pick the
blue box and Bob will get \$0.50 on average.

Try experimenting with other probabilities in the widget, and try to find the optimal strategy for Alice.

The optimal strategy for Alice is to pick the red box with probability $1/3$ and the blue box with probability $2/3$.
In this case let $0 <= p <= 1$ be the probability Bob picks the red box. Bob wins

$$
2 dot P["Alice picks red"] dot p + 1 dot P["Alice picks blue"] dot (1 - p)
  &= 2 dot 1/3 dot p + 1 dot 2/3 dot (1 - p) \
  &= 2/3 p + 2/3 - 2/3 p \
  &= 2/3 approx \$0.67
$$

on average.
Note that this is independent of $p$!

Now notice that if Bob decides to always pick the red box with probability $1/3$ and the blue box with probability $2/3$,
and instead Alice picks the red box with probability $0 <= p <= 1$, then Bob wins
$2 dot 1/3 dot p + 1 dot 2/3 dot (1 - p) approx dollar 0.67$ on average independently of $p$ as well!

This is the [minimax](https://cs.stanford.edu/people/eroberts/courses/soco/projects/1998-99/game-theory/Minimax.html) theorem,
which we will prove using multiplicative weights. The beauty of this algorithm lies in reducing a variety of
situations to the model of choosing between experts for a sequence of decisions and then using the guarantees of the algorithm
to learn about what is possible in the situation. Two player games are one such situation.

# MWU Model

Consider an arbitrary finite zero-sum two player game. Finite means both players have a finite number of choices.
Zero-sum means that both players' payoffs sum to zero. Alice will be the row player and Bob will be the column player.
The row player has $N$ options and the column player has $K$ options.

Let $M in [0, 1]^(N times K)$ represent the costs of this game. So if Alice chooses $i$ and Bob chooses $j$,
then Alice pays Bob $M_(i j)$.
Let the space of probability distributions over $d$ options be
$$
Delta_d = {v in RR^d : v_i >= 0, sum_(i = 1)^d v_i = 1}
$$

If the players independently sample $p in Delta_N, q in Delta_K$, the expected amount Alice pays Bob is
$$
  p^top M q = sum_(i = 1)^N sum_(j = 1)^K p_i q_j M_(i j)
$$

If $p$ is fixed, then Bob can maximize this by choosing a single column $e_j$ with the largest value $p^top M e_j$.
Similarly, if $q$ is fixed, then Alice can minimize this quantity by choosing a single row $e_i$ with the smallest value $e_i^top M q$.
An arbitrary strategy is a probability distribution over the rows for Alice or over the columns for Bob.

We will now describe how the MWU algorithm is applied here. First, try to figure out how it might work yourself.

Alice will be using MWU. She starts with all rows weighted $omega_1 (i) = 1$. The $N$ rows are her $N$ experts.
Each round of the game is a decision. In round t:
1. Alice chooses her row distribution $p_t$ via $p_t (i) = (omega_t (i))/Phi_t$.
2. Bob chooses a best column $j_t$ s.t. $p_t^top M e_(j_t)$ is maximal.
3. They both resolve their choices from their probability distributions and Alice pays Bob the resulting amount.
4. Alice enters the loss function $ell_t = M e_(j_t)$ into the MWU update algorithm, so every row weight is updated accordingly as $omega_(t + 1) (i) = omega_t (i) e^(-epsilon ell_t (i))$. 

The expected round loss is $p_t dot ell_t$, and the distribution for Alice updates in response to the loss incurred by the optimal strategy for Bob.
Recall that we treat $ell_t$ as a vector and a function so $ell_t (i) = (M e_(j_t))_i$ and $x dot ell_t = sum_(i = 1)^N x_i ell_t (i)$.

Applying the bound from the previous page, we get that if $T$ rounds of the game are played, the loss is at most
$$
  sum_(t = 1)^T p_t dot ell_t <= min_(i in [N]) sum_(t = 1)^T ell_t (i) + 2sqrt(T ln(N))
$$

Alice studied computational learning theory, so now she decides to use the multiplicative weights update algorithm against you.

# Optimal Strategy Inequality

For a row distribution $p$, let $U(p) = max_(j in [K]) p^top M e_j$, which is an upper bound on Bob's payoff against Alice if Alice is using $p$.
For a column distribution $q$, let $L(q) = min_(i in [N]) e_i^top M q$, which is a lower bound on what Alice must pay Bob if Bob is using $q$.

Note that every distributional strategy is a weighted average of single choice strategies with the payoffs averaged as well, 
so we have $U(p) = max_(q in Delta_K) p^top M q$ and $L(q) = min_(p in Delta_N) p^top M q$ as well.

For every $p, q$, we have
$$
  L(q) <= p^top M q <= U(p) \
  ==> max_(q in Delta_K) L(q) <= min_(p in Delta_N) U(p) 
$$

This tells us that if Bob can guarantee that he wins at least $x$, then Alice cannot guarantee that she pays Bob less than $x$.
And if Alice can guarantee that she pays Bob at most $y$, then Bob cannot guarantee that he wins more than $y$.
Note that this inequality did not use multiplicative weights at all.

We can use multiplicative weights to say more.

# Von Neumann's Minimax Theorem

<TheoremBlock id="minimax-theorem">

$$
  min_(p in Delta_N) max_(q in Delta_K) p^top M q = max_(q in Delta_K) min_(p in Delta_N) p^top M q
$$

</TheoremBlock>

The inequality above already tells us the left side is greater than or equal to the right side, so it suffices to prove the other inequality.
We will prove this by using the multiplicative weights algorithm in the same way as was described earlier.
By showing that the average regret tends to $0$, we will establish the other inequality.

Note that for $N = 1$ this theorem is immediate as Bob always chooses the largest column value and Alice cannot do anything about it.

<ProofBlock id="minimax-proof" for="minimax-theorem">
<span slot="summary">Proof</span>

Consider playing $T$ rounds of the game where Alice uses MWU and Bob plays optimally as before.

For any round $t$, we have
$$
  U(p_t) = p_t^top M e_(j_t)
$$

So averaging across all rounds yields $p = 1/T sum_(t = 1)^T p_t$.
Then $j^*$ be the fixed column which is Bob's best response to $p$. 
Note that against Alice's average strategy, any fixed column earns its average payout across rounds.
So Bob's round by round best responses do at least that well.
$$
  U(p) &= p^top M e_(j^*) \
  &= 1/T sum_(t = 1)^T p_t^top M e_(j^*) \
  &<= 1/T sum_(t = 1)^T p_t^top M e_(j_t) \
  &= 1/T sum_(t = 1)^T p_t dot ell_t
$$

Now note that against Bob's empirical distribution $q = 1/T sum_(t = 1)^T e_(j_t)$,
each fixed row costs exactly what the row cost on average during the $T$ rounds.
So the regret bound says
$$
  sum_(t = 1)^T p_t dot ell_t &<= min_(i in [N]) sum_(t = 1)^T ell_t (i) + 2sqrt(T ln(N)) \
    &= min_(i in [N]) sum_(t = 1)^T e_i^top (M e_(j_t)) + 2sqrt(T ln(N)) \
    &= min_(i in [N]) T e_i^top M q + 2sqrt(T ln(N)) \
    &= T L(q) + 2sqrt(T ln(N))
$$

Both bounds use the same average argument against the other player's fixed options.
Combining the two bounds yields
$$
  U(p) <= 1/T sum_(t = 1)^T p_t dot ell_t <= L(q) + 2sqrt(ln(N)/T)
$$
So for $delta > 0$, choose $T = ceil((4ln(N))/delta^2)$ and set the learning parameter $epsilon = sqrt(ln(N)/T)$ so that
our values of $p, q$ yield $U(p) - L(q) <= 2sqrt(ln(N)/T) <= delta$.

Let $V_("min") = min_(p in Delta_N) U(p), V_("max") = max_(q in Delta_K) L(q)$. We showed earlier that $V_"max" <= V_"min"$.
Now we take
$$
  0 &<= V_"min" - V_"max" \
    &<= U(p) - L(q) \
    &<= 2sqrt(ln(N)/T)
$$
Taking the limit of $T -> infinity$, we get $V_"min" = V_"max"$.
$$
  min_(p in Delta_N) max_(q in Delta_K) p^top M q &= min_(p in Delta_N) U(p) \
    &= V_"min" \
    &= V_"max" \
    &= max_(q in Delta_K) L(q) \
    &= max_(q in Delta_K) min_(p in Delta_N) p^top M q
$$

</ProofBlock>

This number that both sides are equal to is referred to as the value of the game, where an optimal strategy for Alice ensures she pays at most
the value of the game, and an optimal strategy for Bob ensures he gets paid at least the value of the game.

This theorem also tells us that assuming that both players play optimally, 
it does not matter who announces their strategy first, the other person can always respond to ensure the same payout.
